# Known limitations

- Table 1 and the conceptual Figure 2 are excluded by author instruction.
- Natural-context comparisons include descriptive results for all eight models;
  this package supplies no inferential contrasts for that context. Every retained
  local inferential contrast uses the full eight-model panel.
- Deleted methods' data are absent. Anonymous auxiliary p values and frozen
  full-family critical values preserve the original correction; these calibration
  inputs cannot be independently re-estimated in the reduced package.
- This is fixed-context generation from frozen inputs, not poisoned retrieval.
  Fresh corpus retrieval and stochastic input generation are outside the runnable scope.
- Benign contexts differ in wording/length as well as answer coverage. Coverage
  is labeled-answer string containment, not independent factual verification.
  Original labels and fallback slots are preserved.
- The 68.85/87.14 means are for eight local models and 300 questions. The
  commercial panel is a separate 60-question evaluation; abstract wording does
  not redefine those denominators.
- New responses can vary across model/runtime/hardware revisions. Historical
  commercial endpoints may no longer be available.
- The coauthor-owned illustrative Figure 2 is omitted by author instruction.
- Full-manuscript/Overleaf layout is not rebuilt or certified here.
